# Smart Water Management for Arecanut

## Description
Smart Water Management for Arecanut is an IoT-based irrigation system designed to provide water efficiently to arecanut plants. It uses soil moisture sensors to monitor soil conditions and an ESP8266 NodeMCU to control water pumps and solenoid valves automatically. The system helps reduce water wastage, save time, and improve irrigation management.

## Initialization
The system initializes the ESP8266 Wi-Fi module, soil moisture sensors, relay module, water pump, and solenoid valves. It reads soil moisture levels from three different zones and controls irrigation according to the configured moisture thresholds. This enables efficient and independent watering of arecanut plants in each zone.
